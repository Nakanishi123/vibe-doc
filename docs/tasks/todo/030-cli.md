# CLIを実装する

## 目的

文書の検査、タグ取得、採番候補の取得をコマンドから利用できるようにする。

## 想定スコープ

- `vibe-doc lint`
- `vibe-doc tag`
- `vibe-doc next-index decision`
- `vibe-doc next-index task`

## 完了条件

- lintが仕様で定めたerrorとwarningを表示する。
- tagが重複のないタグを辞書順、一行一件で表示する。
- next-indexがDecisionは1刻み、Taskは10刻みの3桁番号を返す。
